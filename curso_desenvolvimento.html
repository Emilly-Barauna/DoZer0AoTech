Desenvolvimento de Software

Desenvolvimento de software é usar código para criar soluções como sites, aplicativos e sistemas. Existem diferentes caminhos na área, desde o que aparece na tela até dados, segurança e funcionamento interno.

O que você pode fazer nessa área?

criar

Transformar ideias em sites, aplicativos e sistemas que as pessoas possam usar.

Programar

Escrever códigos e construir as funcionalidades que fazem um software funcionar.

Resolver

Encontrar problemas no código, corrigir erros e melhorar aplicações existentes.

Por onde começar?

Não tente aprender várias linguagens de uma vez! Comece entendendo a lógica e escolha uma linguagem para praticar. O importante agora é construir uma boa base. 

01

Lógica de programação

Aprenda a pensar passo a passo e resolver problemas com código

02

HTMS+CSS

Comece criando páginas e entendendo como as interfaces são estruturadas.

03

JavaScript

Dê vida às páginas e aprenda sua primeira linguagem de programação. 

04

Git + GitHub

Aprenda a salvar versões do seu código e compartilhar seus projetos.

05

Banco de Dados

Aprenda como os sistemas guardam, organizam e encontram informações.

06

Projetos

Coloque tudo em prática criando seus primeiros projetos para o portfólio.

Onde esse caminho pode te levar?

Início de carreira Meio de carreira Carreira avançada

Dev Front-end Júnior

Cria interfaces e páginas que os usuários utilizam.

Dev Front-end Pleno

Desenvolve interfaces mais complexas e experiências interativas.

Dev Front-end Sênior

Define soluções avançadas de interface, arquitetura e experiência.

Dev Back-end Júnior

Desenvolve APIs, regras de negócio e integrações.

Dev Back-end Pleno

Desenvolve sistemas, APIs e integrações mais robustas.

Dev Back-end Sênior

Projeta sistemas escaláveis, seguros e de alta performance.

Dev Mobile Júnior

Cria aplicativos para celulares e dispositivos móveis.

Dev Mobile Pleno

Cria aplicativos completos e soluções móveis mais avançadas.

Dev Mobile Sênior

Lidera o desenvolvimento de aplicativos complexos e escaláveis

Dev Full Stack Júnior

Trabalha tanto com a interface quanto com o back-end.

Dev Full Stack Pleno

Atua em toda a aplicação, do front-end ao back-end.

Dev Full Stack Sênior

Domina toda a aplicação e participa de decisões de arquitetura.
